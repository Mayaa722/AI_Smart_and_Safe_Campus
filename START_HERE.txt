SMARTCAMPUS - CONTINUE ON ANOTHER DESKTOP

1. Clone the Abdullah branch or extract that branch's ZIP into a normal folder:
   git clone --branch Abdullah https://github.com/Mayaa722/Smart_Campus_Educational_Model.git
   Keep checkpoints/ intact.
2. Install Python 3.12 and VS Code's Python/Jupyter extensions if needed.
3. Open a terminal in the extracted folder and run:

   py -3.12 -m venv SmartCampus/.venv
   SmartCampus\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python handoff_setup.py

4. Open SmartCampus/vscode/SmartCampus.ipynb and select that venv's interpreter.
   Its default Run All reads saved results and makes NO API calls.
5. For the interface:
   python -m streamlit run SmartCampus/vscode/streamlit_app.py

Read README.md for the exact unfinished work, all seven lectures, API setup,
evaluation limitations and Colab details. Real API keys are deliberately absent.
Your own key is needed only for new live generation, not reading saved work.
Do not delete request ledgers or mistake partial work for completed evaluation.
